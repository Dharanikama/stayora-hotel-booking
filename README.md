Stayora — Hotel Room Booking System

Stayora is a full-stack hotel room booking web application designed to help users explore available stays and make room reservations through a simple, modern interface.

Live Demo

https://stayora-hotel-booking.onrender.com

Features

- Modern, responsive hotel booking interface
- Explore available stays
- User sign-in and account functionality
- Room booking functionality
- MongoDB database integration
- Backend API built with Node.js and Express
- Deployment using Render

Technology Stack

Frontend: React, Vite, CSS

Backend: Node.js, Express.js

Database: MongoDB Atlas

Deployment: Render

Version Control: Git and GitHub

Project Structure

- "client/" — frontend application
- "server/" — backend application
- "README.md" — project documentation

Getting Started

1. Clone the repository.
2. Install the frontend and backend dependencies.
3. Configure the required environment variables.
4. Start the backend server and frontend development server.

Refer to the frontend and backend package configuration files for the available commands.

Environment Variables

Configure the required environment variables in your local environment. These may include:

- "MONGODB_URI" — MongoDB connection string
- "JWT_SECRET" — secret used for authentication
- "ADMIN_EMAIL" — administrator email
- "ADMIN_PASSWORD" — administrator password

Security: Never commit passwords, database credentials, JWT secrets, or ".env" files to GitHub.
